# 🏦 Mini Statement Bank

A simple **Mini Statement Bank Management System** developed using Python.
This project allows users to create bank accounts, deposit money, withdraw money, check balance, and view a mini statement of transactions.

## 📌 Project Overview

The **Mini Statement Bank** is a beginner-friendly Python project designed to demonstrate basic programming concepts such as:

* Classes and Objects
* Functions
* Conditional Statements
* Loops
* File Handling
* JSON Data Storage
* Date and Time
* Menu-driven programming

The project stores account information and transaction details in a JSON file so that the data can be used again when the program is restarted.

## ✨ Features

* 🆕 Create a new bank account
* 💰 Deposit money
* 💸 Withdraw money
* 💳 Check account balance
* 📄 View mini statement
* 🔢 Generate account numbers
* 💾 Save account data using JSON
* 📅 Display transaction date and time
* 🚪 Exit the application safely

## 🛠️ Technologies Used

* **Python 3**
* **JSON**
* **OS module**
* **Datetime module**
* **Random module**
